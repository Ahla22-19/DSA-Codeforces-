## 🌟 Description

A collection of Codeforces problem solutions from **CSEC ASTU weekly contests** and **A2SV (Africa to Silicon Valley) weekly contests**, including detailed contest analysis and problem-solving approaches. This repository documents my competitive programming journey through university club activities and structured training programs.

---

## 🏫 About the Contests

### CSEC ASTU Weekly Contests
Weekly competitive programming contests organized by the **Computer Science and Engineering Club at Adama Science and Technology University**. These contests help students improve their algorithmic problem-solving skills in a collaborative environment.

### A2SV Weekly Contests
Weekly contests from **Africa to Silicon Valley (A2SV)** , a program that trains African students in data structures, algorithms, and problem-solving to prepare them for internships and jobs at top tech companies.
